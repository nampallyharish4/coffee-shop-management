A robust, enterprise-grade **Full-Stack Coffee Shop Management System** designed to streamline operations, from order taking to inventory tracking and performance analytics.

---

## 🌟 Overview

This system provides a comprehensive solution for coffee shop owners and staff. It features a modern, responsive React frontend coupled with a secure, high-performance Spring Boot backend. 

### 🎯 Key Target Roles
- **Admins:** Oversee the entire operation, manage users, and analyze business growth.
- **Cashiers:** Efficiently process orders through a streamlined POS interface.
- **Baristas:** View and manage orders in real-time via the Kitchen Display System (KDS).
- **Inventory Managers:** Monitor stock levels and ensure supplies are never low.

---

## 🚀 Core Modules

### 🛒 Point of Sale (POS)
- **Fast Checkout:** Intuitive menu with category filtering and search.
- **Order Customization:** Support for discounts and real-time tax calculation.
- **Digital Receipts:** Generate printable receipts immediately after order completion.

### 📋 Kitchen Display System (KDS)
- **Real-Time Updates:** Baristas see new orders instantly without page refreshes.
- **Audio Notifications:** Automatic alerts when new orders arrive.
- **Workflow Management:** Track order status from *In Preparation* to *Ready* and *Completed*.

### 📦 Smart Inventory Management
- **Automated Deduction:** Stock levels are automatically updated as orders are processed.
- **Recipe Mapping:** Link menu items to specific ingredients for precision tracking.
- **Low Stock Alerts:** Visual warnings for items reaching critical levels.

### 📊 Business Analytics
- **Live Dashboard:** Real-time metrics for Revenue, Order Volume, and Average Order Value.
- **Visual Insights:** Interactive charts showing sales trends and top-performing items.
- **Staff Performance:** Track orders and revenue generated by each team member.

## 📥 Getting Started

### 1. Prerequisites
- **Java 21** or higher.
- **Node.js** (v18.x or v20.x recommended).
- **MySQL Server** 8.0+.
- **Maven** (included via wrapper).

### 2. Database Initialization
Run the following script in your MySQL environment:
```sql
source setup-mysql.sql;
```
*This creates the `coffee_shop` database and a dedicated user `coffee_admin`.*

### 3. Quick Launch (Recommended)
Simply run the root-level batch script:
```bash
start_app.bat
```
*This will automatically launch the backend (port 8081) and frontend (port 3000) in separate windows.*
